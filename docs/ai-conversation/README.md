## 검증·재생성

원문 UI 메시지 수·순서·ID·역할·시각·마스킹 결과를 대조했고, 파일 SHA256을 manifest에 기록했다. 공개 파일에 원시 로그나 비밀값을 복사하지 않았다. 내보내기 검증3개는 전체 메시지/긴 텍스트 보존, 재사용된 자격증명 마스킹, 다른 대화·중복·미지원 콘텐츠 차단을 검사했다.

전체 텍스트와JSONL에는 `.gitattributes`의 `-text`를 지정해 Git 개행 변환을 막았다. 텍스트 원문의 후행 공백·CRLF도 보존하므로 이 기록 파일만 공백 경고를 비활성화했다. 운영체제가 달라도 파일 원문과 manifest의 SHA256을 같은 바이트로 검증할 수 있다.

최초 검증에서는 파일명의 하이픈과 Python 모듈 import 이름이 달라 실패했다. 파일명을 수정한 뒤3개가 통과했다. 대화 원문은 수정하지 않았다.

```powershell
python -m unittest discover -s scripts -p test_export_ai_conversation.py
python scripts/export_ai_conversation.py --source "현재 대화의 로컬 JSONL 원문 경로" --output docs/ai-conversation
```

원문은 API 키·도구 로그를 포함할 수 있으므로 저장소에 직접 추가하지 않는다. 재생성하면 메시지 수·생성 시점·마스킹 내역을 다시 검토하고 이 안내의 개수도 갱신한다.
