- 검증: streaming start/progress/result 및 화면 집계, 요청 후 키 입력란 공란을 확인했다. 내장 브라우저 download 이벤트는 12초 내 관측되지 않았으나 이후 사용자가 제공한 정상 JSON 파일로 다운로드·원본 값 보존을 확인했다. 도구의 이벤트 미관측을 제품 다운로드 실패로 단정하지 않는다.

## 2026-10-11 — 두 번째 이력 GET (화면 관측만 보존)

- 실행 ID: `b01691b6-4bfa-45c0-9e29-93df1102fbca`, 출처 EXTERNAL. 같은 가상 사번의 LIST GET 1회, 동시성 1, 연결 제한 5,000ms, 전체 요청 제한 30,000ms, 실행 최대 40,000ms, 호출 예산 1.
- 화면에서 COMPLETED, 관측 1, 이벤트 3, HTTP_RESPONSE 1건, HTTP 200 1/1(100%)를 확인했다. 키 입력란이 공란으로 돌아왔다. 검사한 명세 항목의 차이는 미관측이었다. 이는 모든 Swagger 동작이 검증됐다는 뜻이 아니다.
- 완료 HTTP n=1. 화면 표시 평균/p50/p95/p99/최댓값은 모두 2,365.36ms, 평균−중앙값 0.00ms, queueWait 0.30ms였다. n=1의 백분위수는 한 관측의 반복 표시이므로 tail 분포를 입증하지 않는다.
- 사용자가 원본 JSON 다운로드 버튼이 동작하지 않아 새로고침했다고 알렸다. 이 실행의 원본 JSON·정확한 소수점·요청 시각·응답 바이트는 미보존이며 만들어 채우지 않는다. 화면 관측값을 원본 JSON으로 재구성하지 않는다.
- 첫 조건과 두 번째 조건은 requestTimeoutMs가 달라 별도 해석한다. 원본 JSON 기반 엑셀의 첫 초안에는 첫 실행만 포함했다. 두 번째 화면 관측은 원본 보존 후 반복 실험으로 확인할 대상이다.
- 사용자가 다음 순차 LIST GET 총 3회, 동시성 1, 간격 2,000ms, 연결 제한 5,000ms, 전체 요청 제한 30,000ms, 실행 최대 100,000ms, POST/자동 재시도 없음 조건을 승인했다. 스크립트 실행은 아직 하지 않았으며 새 표본을 기록하지 않는다. [직접 실행 절차](MEASUREMENT_SCRIPTS.md)를 따른다. 운영 정책은 TODO다.

## 원본 기반 Excel 초안과 분석 수정

- 첫 원본만 사용한 초안: EXTERNAL 실행 1개, 전체 n=1, 완료 HTTP n=0, 전송 중단 n=1. 완료 평균·p50·p95·p99·최댓값은 TODO다. 두 번째 화면 관측은 이 원본 집계에 포함하지 않는다.
- Summary/Candidates/Attempts/Runs 시트에 조건·원본 SHA-256·통계별 분모·Type 7·중도절단 한계를 기록했다. 원본이 늘면 오프라인 빌더를 다시 실행한다.
- 재계산·수식 오류 검사 0건, 후보 입력 변경 후 원복을 검증했다. Windows 이미지 렌더러의 Vulkan 초기화 오류로 시트 시각 검증은 미완료이며 배치가 검증된 최종본으로 표시하지 않는다.
- 통계 구현 수정: 중단 경과 10,003.931728ms에는 취소 지연이 포함되므로 후보 10,001ms를 초과한 완료 응답이라고 단정할 수 없다. 완료 지연이 미관측인 전송 중단은 후보 비교에서 미확정으로 표시한다. 이 실제 관측을 사용한 회귀 테스트를 포함한 프론트 테스트 8개가 통과했다. 이는 새 외부 측정 표본을 추가한 것이 아니다.
