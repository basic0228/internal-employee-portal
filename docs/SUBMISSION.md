### 구현하지 않은 부분 / 제외 범위

- 비밀번호 변경 및 최초 비밀번호 강제 변경: **미구현**.
- 자동 SQL 마이그레이션 실행 도구: **미도입**. SQL 파일을 확인해 수동 적용한다.
- 운영 세션 만료·쿠키·프록시 설정의 별도 확정: **미완료**. 기존 배포 설정을 유지했다.
- 회원가입·가입 승인·MAC/IP 수집: 사용자 선택으로 **범위 제외**.
- 가입/수정 시 자동 배경 조회, 상세 결과 영구 저장, 30일 자동 삭제: 최종 정책에 따라 **범위 제외**.
- 재조회 최소 간격·결과 유효기간: 실측으로 정할 수 없어 **기간 정책 미설정**. 완료 후 명시적 재조회 확인은 구현했다.

## 검증 결과와 남은 작업

**로컬:** 최종 백엔드97개, 실패0·오류0·skip0(업무 이력15개 포함). 프론트는 앞선 업무 변경에서23개 통과했고 이후 프론트 소스는 변경하지 않았다. 관리자 UI opt-in 빌드·JAR 패키징은 앞선 구현에서 통과했다. 번들 크기 경고는 남는다. H2/모의 HTTP는 PostgreSQL·외부 API 운영 검증을 대체하지 않는다.

**운영:** EMP-001 POST1+상세GET1로 즉시clear·이력/열람 저장 확인. EMP-002 POST1+자동GET1+수동GET1로pending→flagged 수동 발견 확인. 모달 재열기 후 이력 유지·상세 초기화 확인. 비로그인 관리자 이력 API 401 확인. 자동 중단 원인은 원본 계측 없이 특정 HTTP 오류로 추정하지 않았다. [검증 증빙 JSON](measurements/business-validation.json)은 후속 업무 관찰·로컬 USER 결과·97개 테스트 보고서를 보존하고 기존 Lab 표본과 구분한다.

**운영 USER 도구:** [verify-user-access.ps1](../scripts/verify-user-access.ps1)를 준비했다. 로컬 실제 HTTP에서 본인정보200+본인/다른 대상12경로403, 유효 CSRF logout204를 확인했다. 운영 기존 USER 계정으로 실행한 결과는 아직 없다. 필요 시 아래 명령에서 로그인 정보를 직접 입력한다. 외부 Background Check 실험이 아니다.

```powershell
.\scripts\verify-user-access.ps1 -Execute
```
